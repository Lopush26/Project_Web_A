Proyek Terbaru

OSCAR – Oral Squamous Cell carcinoma Automatic Recognition

Proyek PKM KC tahun 2026 berupa sistem end-to-end untuk deteksi dini Oral Squamous Cell Carcinoma (kanker rongga mulut) .

Di sisi IoT, menggunakan ESP32 yang dilengkapi tiga chip LMP91000 untuk membaca tiga biomarker saliva secara bersamaan melalui sensor SPCE. Data kemudian dikirim ke Raspberry Pi menggunakan UART.

Raspberry Pi memproses data dan menjalankan model Graph Neural Network dengan akurasi sekitar 97%. Hasilnya dikirim ke dashboard cloud yang dibangun menggunakan Next.js dan disimpan di database MySQL.

Robot Mochi

Proyek pribadi berupa robot interaktif kecil berbasis ESP32-C3 SuperMini. Robot ini menampilkan ekspresi wajah berbeda di layar OLED sesuai cara pengguna menyentuhnya (single tap, double tap, dan lainnya).

Menempatkan sensor kapasitif TTP223 di balik casing tipis, serta merancang sistem daya menggunakan baterai Li-Po dan modul TP4056 agar robot dapat beroperasi secara mandiri.
